# پذیرش نهایی مرحله P2

## دامنه

این شاهد مراحل `P2.4` تا `P2.15` را پوشش می‌دهد و تکمیل مرحله مادر هویت، سازمان و مجوزدهی را ثبت می‌کند.

## خط‌مبناهای امنیتی

- Argon2id با حافظه `32 MiB`، تکرار `3` و Parallelism برابر `1`
- طول گذرواژه بین ۱۵ تا ۱۲۸ نویسه و بدون Normalization
- نشست Server Side با Secret تصادفی ۲۵۶ بیتی و ذخیره فقط Hash آن
- انقضای بیکاری ۸ ساعت و انقضای مطلق ۷ روز
- Cookie از نوع HttpOnly، SameSite=Lax و Secure در تولید
- محافظت CSRF برای تمام عملیات تغییردهنده
- محدودسازی ۵ شکست ورود در پنجره ۱۵ دقیقه

## سازمان و مجوز

- سازمان جاری در نشست و افزایش `sessionRevision` هنگام تغییر
- تراکنش PostgreSQL با `SET LOCAL ROLE` و زمینه سازمان یا کاربر
- RBAC، قواعد رابطه‌ای، قواعد وضعیت منبع و اولویت Explicit Deny
- دعوت یک‌بارمصرف ۷۲ ساعته با Token هش‌شده
- مدیریت وضعیت عضویت، نقش‌ها، تیم‌ها و اعضای تیم

## رابط

- فارسی و راست‌به‌چپ
- فونت محلی Vazirmatn
- ورود، انتخاب سازمان، اعضا، دعوت و تیم‌ها
- Proxy سمت سرور Web به API بدون نگهداری Secret در Browser Storage

## دروازه پذیرش

- آزمون‌های هدف P2
- آزمون منفی و بین‌سازمانی
- Migrationهای نسخه 5 تا 9
- پذیرش واقعی PostgreSQL
- Typecheck، معماری، امنیت مخزن و Contract Drift
- ساخت چهار برنامه
- اجرای کامل مجموعه آزمون‌ها
- ممیزی بسته‌شده P2
- فضای کاری پاک

## نتیجه
