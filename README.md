# OrgaWork

سامانه سازمانی مدیریت پرونده‌ها، اقدامات، پیگیری‌ها، یادآورها و گزارش‌دهی.

## وضعیت پروژه

- فاز بنیاد محصول: تکمیل‌شده
- مرحله جاری: P1 — پایه پروژه و فضای کاری
- وضعیت برنامه‌نویسی: آغازشده

## الزامات قطعی رابط کاربری

- تمام متن‌های قابل مشاهده باید فارسی روان باشند.
- استفاده از واژه‌های انگلیسی در رابط کاربری ممنوع است.
- جهت رابط کاربری راست‌به‌چپ است.
- تمام تاریخ‌های نمایشی و ورودی بر پایه تقویم هجری شمسی هستند.
- زمان در لایه فنی به‌صورت استاندارد جهانی ذخیره و منتقل می‌شود.

## ساختار اصلی

- `apps` — برنامه‌های اجرایی
- `packages` — بسته‌های مشترک و زیرساختی
- `modules` — ماژول‌های دامنه
- `infra` — زیرساخت، استقرار و مهاجرت‌ها
- `tools` — ابزارها و بررسی‌های توسعه
- `docs` — مستندات و وضعیت پروژه
